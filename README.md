# Flask Web App

A simple web application built with Flask to learn backend web development using Python.

## Features

- Flask backend
- HTML & CSS frontend
- User-friendly interface
- Lightweight and easy to understand

## Tech Stack

- Python
- Flask
- HTML5
- CSS3

## Project Structure

```
Flask-Web-App/
│── app.py
│── index.html
│── style.css
│── README.md
│── requirements.txt
```

## Getting Started

1. Clone the repository
2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
python app.py
```

4. Open your browser and visit:

```
http://127.0.0.1:5000
```

## Purpose

This project was built to strengthen my understanding of Flask, routing, templates, and web application development using Python.
